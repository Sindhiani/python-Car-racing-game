# 🚗 Car Racer – Python Game

Car Racer is a simple and addictive 2D racing game created using **Python** and developed in **Visual Studio Code**. The player must dodge incoming cars and survive as long as possible while the game speed gradually increases.

## 🎮 Gameplay
- Control the car using keyboard keys
- Avoid crashing into other vehicles
- Score increases the longer you survive
- Game difficulty increases over time

## 🛠️ Built With
- Python
- Pygame
- Visual Studio Code

## ✨ Features
- Smooth controls
- Increasing difficulty
- Clean and simple UI
- Beginner-friendly Python project
